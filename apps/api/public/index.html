Comment ça marche

  1. Forgez votre bible — importez le Markdown de votre univers.
  2. Mesurez sa richesse — cinq axes, et les zones floues révélées.
  3. Vivez-le — sessions narrées, dés serveur, Souffle limité.
  4. Canonisez — les inventions du MJ enrichissent votre bible.
